# Setup Instructions

## 1. Create the GitHub repository

Go to https://github.com/DRIPDROPS and create a new repository named **setx-history**

## 2. Push this code

```bash
cd ~/setx-history-repo
git remote add origin https://github.com/DRIPDROPS/setx-history.git
git push -u origin claude/southeast-texas-work-01QuZJGw5iAhFf7RCURFGMD8
```

## 3. Run the app

```bash
npm install
./start.sh
```

Visit http://localhost:3002
